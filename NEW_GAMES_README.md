# Пять новых игр

Страница `new-games.html?kind=…`: `p52`, `xo`, `maze`, `bonus`, `domino`.
Правила взяты из предоставленных PDF «Плюс пять — минус два», «Математические крестики-нолики», «Лабиринт», «Бонусы», «Математическое домино».

## Механика

| Игра | Выдача и попытки | Баллы |
|---|---|---|
| Плюс 5 — минус 2 | Все задачи сразу, попытки до зачёта; значение и пример | −2 за каждую неверную попытку, +5 за верное значение с примером; отрицательный итог допустим |
| Крестики-нолики | 5×5, одна попытка на клетку | Каждая верная клетка: 1 + число верных соседей по стороне. Полное поле — 105 |
| Лабиринт | 24 задачи, первая №1; после сдачи следующая; верные 3/7/11/15 дополнительно выдают 6/10/14/18 | Шесть блоков по четыре задачи стоимостью 2/3/4/5/6/7; ошибка — 0 |
| Бонусы | 120 минут, по восемь задач ценой 3/4/5; сначала 1/9/17, затем следующая в той же группе | Выбранный бланк: +1 (6 шт.), +2 (4), +3 (2), ×2 (6), ×3 (4), ×4 (2). Расходуется и при ошибке; ошибка — 0 |
| Домино | Общий набор, одна карточка у команды, один держатель карточки, две попытки | Первая верная — сумма; вторая верная — максимум; две ошибки — минус минимум. 0\|0: одна попытка, +10 или 0 |

В «Плюс 5 — минус 2» совпадение числа не заменяет проверку примера и оптимальности ведущим. Файлы или интерактивное решение могут служить примером. Исправление оценки и возврат отправки пересчитывают баллы по истории. После автоматического завершения возврат открывает игру снова, если время ещё осталось; явное завершение ведущим не отменяется. В домино возврат невозможен, если карточка уже занята другой командой.

Параметры, которых PDF не фиксируют, задаёт ведущий: время (кроме «Бонусов»), число задач для +5/−2 и максимальное число точек домино. По умолчанию 90 минут, 12 задач, двойное шестёрочное домино (28 карточек). Это настройки, а не дополнительные правила. Домино по умолчанию проводится на бумаге; доступен онлайн-режим. Одна игра поддерживает 1–32 команды.

## Общие модули

Используются существующие TaskManager, банк, XLS/XLSX, LaTeX, конструктор разрезаний, загрузчик файлов, ReviewGrid, SavedGames и BankAuth. Правильные ответы остаются на сервере. Невыданные условия лабиринта, бонусов и домино также не передаются командам.

На странице создания и в редакторе есть «Скачать шаблон XLSX». Каждый вид получает свой набор позиций и дополнительных столбцов: координаты клеток, блоки/цены/выходы, группы цен, точки домино. Лист «Инструкция» содержит правила заполнения; фиксированные параметры позиций менять нельзя. Существующие столбцы импорта сохранены. После импорта нажмите «Применить к черновику», затем «Сохранить задачи игры».

Сценарий сохраняет настройки и версии всех задач. Запуск создаёт новую игру без старых ответов. Банк и сценарии приватны для вошедшего ведущего; ссылки команд дают доступ только к собственной сдаче.

## Установка и хранение

`new-games.sql` — добавочная миграция: только новые таблицы и функции `ng_*`, собственная очистка и закрытые права. Серверные функции и данные четырёх прежних игр не заменяются. Общая таблица копий задач и реестр файлов получают записи только новых экземпляров.

`new-game-files.ts` использует единый `game-files-core.ts`. Для редактора Supabase создайте одиночный файл командой `python3 bundle-game-files.py --new > /tmp/new-game-files-deploy.ts` и разверните **new-game-files** с включённой проверкой JWT. Существующий endpoint **game-files** не требуется обновлять. Секрет service role используется только средой Supabase.

Задачи, ответы, интерактивные решения и вложения удаляются через 7 дней после завершения; итоговые результаты — через 30 дней; неактивные черновики — через 30 дней. Собственная SQL-очистка помечает файлы истёкшими; существующая очистка Storage удаляет их байты. Постоянный банк и сохранённые сценарии остаются до ручного удаления.

## Проверки

`new-games-tests.sql` выполняется в транзакции с ROLLBACK: отрицательные баллы, полный XO=105, выходы лабиринта, очереди/расход бонусов, эксклюзивность и все варианты баллов домино, отсутствие ключей в ответах ученикам, права на файлы, приватность/повторный запуск сценариев, сроки 7/30/30. Все SQL-тесты пройдены на проекте Supabase 26.11.2026.

Для уже установленной первой версии: `new-games-return-fix.sql` обновляет только `ng_api`, сохраняя возможность возврата после автоматического завершения.
