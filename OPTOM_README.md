# Оптом дороже

Статическая игра без Google-сервисов и сторонних JavaScript-зависимостей.
Frontend: GitHub Pages. Backend: Supabase Postgres RPC.

## Запуск

1. Выполните `optom-schema.sql` один раз в SQL Editor Supabase.
2. Откройте `/math-games/optom-dorozhe.html`, нажмите «Создать игру».
3. Сохраните личную ссылку ведущего отдельно. Она также хранится в текущем браузере.
4. Сохраните 3–6 названий команд. Раздайте личные ссылки капитанам.
5. Проверьте 24 задачи и ключи; сохраните изменения. Условия можно раздать отдельно.
6. Нажмите «Старт: 90 минут». Сервер самостоятельно блокирует сдачи по истечении времени.
7. Проверяйте комплекты; фото и кнопки проверки открываются в одном окне.

## Правила

Комплект: 1–8 разных задач; каждая задача сдаётся один раз. Прежняя таблица баллов сохранена в `od_score` и интерфейсе. Непроверенные комплекты не входят в сумму. Отрицательные баллы учитываются. Ведущий может исправлять оценки после окончания игры. При отмене отдельного ответа его запись остаётся в истории, задача освобождается, размер и балл оставшейся части комплекта пересчитываются.

Число/набор чисел проверяются автоматически, непонятная запись уходит ведущему. Для текста автоматически принимается совпадение с ключом; неизвестный текст проверяется вручную. Режим «Вручную» всегда требует проверки. Ключи с альтернативами разделяются `|`, числа набора — `;`. Ключи перенесены из прежней версии, №4,7,9,14,17,18,21,23 — ручные.

## Безопасность и хранение

На всех таблицах включён RLS без публичных политик; прямой доступ для anon/authenticated отозван. Единственная внешняя функция — `od_api`, с фиксированным пустым search_path и явной проверкой полномочий. Ключ ведущего имеет 244 случайных бита и хранится в БД как SHA-256. Ссылки команд тоже содержат случайные секреты; ведущий видит их в своей закрытой выдаче. Секреты находятся во фрагменте URL, не в запросах к GitHub. Публичное табло содержит только имена и суммы. Правильные ответы, сдачи других команд и фото недоступны капитанам.

Фото уменьшается до 1600 пикселей и сохраняется в закрытой таблице внутри комплекта (JPEG data URL, максимум 2.8 МБ). Это не публичный Storage bucket; фото доступно через авторизованный RPC только ведущему или своей команде. Не используйте игру для чувствительных персональных данных. Publishable key намеренно публичен и не даёт прямого доступа к таблицам.

Сдача транзакционна, операции сериализуются блокировкой строки игры. UUID запроса обеспечивает идемпотентный повтор после обрыва сети; попытка сохраняется локально. Время и баллы определяются сервером. Табло обновляется раз в 5 секунд, таймер — каждую секунду с поправкой по серверным часам.

Новая игра сохраняет старую целиком по её ссылкам, копирует ключи и создаёт новые ссылки. Экспорт JSON доступен ведущему. Секрет ведущего нельзя восстановить после потери всех его копий без администратора базы.

Создание игр открыто без регистрации. Для публичного использования с большой аудиторией потребуется добавить ограничение создания игр на сервере (например, учётную запись преподавателя). Не публикуйте service_role и ключи ведущих в репозитории.
