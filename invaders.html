Правила игры

У команд одинаковые задачи стоимостью 3, 5, 8, 11 и 15. Одна попытка на задачу. Верные непотраченные задачи образуют резерв.

Свободная клетка стоит одну задачу не дешевле её стоимости. Для перезахвата нужно на одну задачу больше предыдущей ставки; каждая также не дешевле клетки. Задачи прежнего владельца не возвращаются. Захватывать можно только по стороне своей территории.

Чужие старты и четыре соседние по стороне клетки защищены. Места определяются суммой стоимостей принадлежащих команде клеток, включая старт. Оценку уже потраченной задачи изменить нельзя.
