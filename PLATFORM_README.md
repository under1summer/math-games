# Общие возможности игр

Сайт: https://under1summer.github.io/math-games/

Работают «Оптом дороже», «Математическая абака» и «Перестрелка». «Биржа» ожидает исходных согласованных правил.

## Онлайн и аудитория

Перед стартом ведущий выбирает «Формат игры» и сохраняет режим:

- Онлайн: команды отправляют ответы по индивидуальным ссылкам.
- В аудитории: команды видят задачи/табло, а ответы сдают на листочках. Сервер блокирует отправку командами. Ведущий вносит ответы в «Ответы с листочков» (в «Перестрелке» — «Внести ответ с листка»). Для «Оптом дороже» можно внести комплект до 8 задач, сохраняя комплектное начисление.

После старта формат фиксируется. Командные ссылки создаются и для аудитории — их можно использовать для просмотра. Личная ссылка ведущего остаётся секретом управления.

## Задачи

Условия и ключи заполняются вручную в редакторе ведущего или импортируются из .xls/.xlsx. Кнопка «Скачать шаблон Excel» выгружает текущую структуру поля с кодами задач. В шаблоне могут быть ключи — его не раздают командам.

Колонки: `Код`, `Условие`, `Режим`, `Ответ`; для абаки также `Название темы`. Другие колонки шаблона помогают ориентироваться.

Коды:

| Игра | Код |
|---|---|
| Оптом дороже | 1–24 |
| Абака | номер темы:номер задачи, например 1:2 |
| Перестрелка | s:обойма:номер, например s:1:3; аптечка m:1–m:20 |

Можно импортировать часть задач. Выберите лист, проверьте предпросмотр, перенесите данные в редактор и сохраните задачи. Неизвестные и повторяющиеся коды, неизвестные режимы и пустые ключи автопроверки отклоняются. Файл читается локально в браузере, макросы и формулы не запускаются. Условия пока текстовые; вложенные картинки Excel не импортируются. Ограничение файла 10 МБ, листа — 1000 строк задач.

В абаке у всей темы должно быть одно название. Условия абаки и Перестрелки фиксируются после старта; импорт доступен до старта. В «Оптом дороже» сохранено прежнее ручное редактирование ключей, но Excel импорт тоже только до старта.

Кнопка будущего банка пока недоступна. Общий банк, его редактор и интерактивные модули не реализованы; точки подключения и поля идентификаторов сохраняются.

## Проверка

Режимы задач: `Число`, `Текст`, `Набор чисел`, `Вручную`. Альтернативные ключи разделяются `|`, элементы набора — `;`. Числовая нормализация в абаке также поддерживает обычные дроби; в двух других играх используйте десятичные значения. Полное решение по смыслу проверяет преподаватель.

При наличии ключа сервер автоматически проверяет распознанный ответ. Текст, не совпавший с ключом, нераспознанный ввод и ручные задачи остаются на проверку. Ведущий может подтвердить или изменить результат, включая автоматический. В «Оптом дороже» и абаке сохранены фотографии решений и ручная допроверка картинок.

В Перестрелке команда выбирает выстрел/аптечку, задачу, цель выстрела и вводит текст ответа. Сдача резервирует единственную попытку. Пока ответ ожидает проверки, HP/меткость не меняются. При вердикте событие применяется по порядку регистрации вердиктов. Ведущий видит очередь в порядке получения. После окончания можно допроверить вовремя полученные ответы; до этого итог помечен предварительным.

Изменение вердикта в Перестрелке обновляет существующее событие, не добавляет попытку и пересчитывает последующие события. Уже выбранное случайное число выстрела сохраняется. Непроверенную сдачу ведущий отменяет в очереди, проверенную — в журнале. Отмена освобождает задачу, сохраняя историю. Ручной ввод вердикта ведущим без текстовой сдачи тоже сохранён.

## Установка и проверки

Для уже установленной версии от 25 ноября 2026: однократно выполните `platform-update.sql`. Он добавляет `online` к трём играм, закрытую таблицу `ps_submissions`, приватные ключи Перестрелки и обновляет RPC. Данные прежних игр не удаляет. Для новой установки используйте три актуальных `*-schema.sql`, затем миграцию повторять не нужно.

Проверки: `platform-tests.sql`, `optom-tests.sql`, `abaka-tests.sql`, `perestrelka-tests.sql` — SQL Editor от владельца, с откатом тестовых данных. Общие тесты покрывают автопроверку, ручное исправление, сохранение случайности, единственную попытку, повтор запроса, секретность ключей, изоляцию ответов команд и блокировку онлайн-отправки в аудитории во всех трёх играх.

`task-tools.js` — общий импорт Excel, формат проведения и ввод листочков. `xlsx.full.min.js` — SheetJS CE 0.20.3, лицензия Apache-2.0, исходная поставка: https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js . Библиотека хранится вместе с сайтом; Google-сервисы не используются.

## Табличная ручная проверка

В «Оптом дороже» и «Перестрелке» ведущий нажимает ячейку команды и задачи; в абаке — ячейку в отдельной таблице команды. Статусы: ✓ верно, ✕ неверно, ⌛ ожидает, — не сдано. Окно показывает текст ответа, условие, ключ (свёрнут), фотографию при наличии и кнопки вердикта. Можно изменить автоматическую оценку и допроверить после окончания. В абаке также сохраняется комментарий.

В аудитории пустую ячейку абаки/Перестрелки можно оценить по листочку во время игры. Ответ регистрируется с пометкой «Проверка решения на листочке». В абаке сохраняется порядок задач внутри темы; в Перестрелке для выстрела выбирается цель. В «Оптом дороже» сначала вносится целый комплект, затем оцениваются его ячейки — комплектное начисление сохранено. Онлайн несданные задачи оценить нельзя.

Для уже установленной версии выполните однократно `perestrelka-review.sql`: это проверка прежних ответов, которые ведущий вносил без текста. Повторное выполнение безопасно. В актуальную первоначальную схему и общую миграцию функция уже включена. `review-tests.sql` проверяет права, сохранение попыток и случайных чисел и полностью откатывает фикстуры. `review-grid.js` — общий интерфейс ячеек и окна проверки. Данные других игр не меняются.
