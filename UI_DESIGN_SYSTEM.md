# Math Games · Candy UI

Единое оформление каталога, банка, сценариев, редактора задач и девяти форматов платформы. Биржа сохраняет прежний статус подготовки задач: проведение не добавляется этим обновлением.

## Подключение

В конце `<head>` после прежних стилей подключите:

```html
<link rel="stylesheet" href="./platform-ui.css?v=candy-2">
<script src="./platform-ui.js?v=candy-2"></script>
```

Новые страницы наследуют базовые формы, кнопки, карточки, навигацию, таблицы, диалоги, статусы, фокус и мобильные размеры. В `new-games.html?kind=…` тема выбирается автоматически. Для отдельной новой игры добавьте её код в определение темы. Клиентский UI не обращается к API и не изменяет серверные данные.

## Токены

Все новые компоненты используют CSS-переменные из `platform-ui.css`: молочный фон `--milk`, сливовый текст `--plum`, поверхности `--paper`, линии, тени и радиусы. Конфетная палитра: `--strawberry`, `--lavender`, `--mint`, `--lemon`, `--sky`, `--peach`; дополнительные оттенки получены из этой палитры. `--accent` задаётся игрой. Математические цвета клеток остаются предметными данными задачи, а не брендовыми цветами.

## Компоненты

- `mg-primary` — главное действие, тёмное с контрастным текстом. `mg-quiet` — второстепенное; `mg-danger` — разрушительное.
- `mg-fields`, `mg-form` — связанные поля в 2–3 колонки; `mg-wide` — условие/большое поле на всю строку. Числа имеют короткие поля.
- `mg-advanced` — раскрываемые дополнительные параметры без потери значений.
- `mg-toolbar` — панель сохранения и импорта; остаётся доступной при прокрутке редактора.
- `mg-topnav` — общая навигация, активный раздел, ссылка обхода к содержимому.
- `ReviewGrid` — общая проверка: компактная матрица, закреплённые заголовки, сохранение прокрутки и фокуса, модальное окно с действиями.
- `mg-cutting` — общая оболочка интерактивного рисунка, доступная палитра, масштаб 100–300%, отмена шага. Правила разрезания и алгоритм проверки не изменены.
- `MGUI.icon(name)` — локальные SVG, без внешнего сервиса и шрифтов иконок.
- `MGUI.feedback(text)` — короткая ненавязчивая обратная связь.
- `MGUI.progress(id, correct, anchor)` — визуальные отметки первого, пятого и десятого верных решений. Только для команды, на основе уже подтверждённых результатов. Не добавляет очков и ничего не записывает в базу; история показа хранится в sessionStorage.

Статусы: ✓ верно, ✕ неверно, ⌛ на проверке, — не сдано, ↶ возвращено. Цвет не заменяет текст/символ. По наведению кнопки показывают действие, иконки декоративны для скринридеров. Обычные поля имеют доступные имена. Изменение темы и отключение анимации следуют `prefers-reduced-motion`.

## Редактор и сохранение

Первый экран: тип задания, условие, способ проверки и ключ (только при автоматической проверке). У разрезаний скрыты неприменимые текстовые поля. Название для банка и политика вложений — в дополнительных настройках. XLS/XLSX, шаблон и инструкция сгруппированы в отдельном блоке. Банк на компьютере расположен рядом, на телефоне — ниже редактора. При нескольких черновиках доступны сохранение всех и отдельной задачи. Выбор версии из банка, независимость игровых копий и приватность не меняются.

## Проверки

- `bank-ui-tests.html`: создание, редактирование, переключение черновиков, интерактивная задача.
- `bank-selection-tests.html`: игровые копии/версии банка, позиции и изменения тем, сохранение со сценарием.
- `ux-ui-tests.html`: условные поля, сохранение, палитра/клавиатура/отмена/масштаб, формулировки, шаблоны пяти игр, XLS/XLSX, предпросмотр и удаление файлов, обязательное вложение, действие ручной проверки.
- `ux-responsive-check.html`: реальные iframe viewport 390/768/1280 для проверки переполнения и адаптивных переходов.
- `cutting-tests.js` и `cutting-extended-tests.js`: прежние алгоритмы разрезаний.

Тесты UI используют офлайн-адаптеры, не изменяют настоящие задачи/игры и не отправляют файлы. SQL, игровые правила, схема, RLS, Storage и авторизация этим рефакторингом не меняются.
